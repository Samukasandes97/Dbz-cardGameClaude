# DBZ Card Game - projeto organizado

| Pasta | Conteudo |
|---|---|
| 01_HEROIS/<Heroi>/ | cada heroi: Retrato, Skins_retrato, Vozes, Efeitos_sonoros, Efeitos_especiais (habilidades e golpes), Entrada, Transformacao, Comeback (videos MP4 + voz + efeitos) |
| 01_HEROIS/_COMUM/ | itens compartilhados: cenas padrao, efeitos sonoros por categoria, icones, identidade visual, VFX e referencias dele |
| 02_CARTAS/ | starter decks (Goku, Vegeta), molduras (comum, rara, super rara, lendaria, premium, 3D) e demos |
| 03_CENARIOS/ | mapas/cenarios do tabuleiro |
| 04_ARENA/demo_jogavel/ | O JOGO: abra game4.html no Chrome (pasta a/ ao lado) |
| 05_DEMOS/ | videos de demonstracao (NEW_completo em partes: cat parte_* > NEW_completo.mp4) |
| 06_COMBATENTES_AUDIO/ | audios de combatentes (cartas de unidade) |
| 07_DOCUMENTOS/ | regras, catalogo de herois, manifesto, mapa de duplicados |
| 08_MUSICAS/ | trilhas enviadas (ainda nao distribuidas por cenario) |
| 99_ORIGINAIS_ENVIADOS_PELO_USUARIO/ | originais como enviados |
